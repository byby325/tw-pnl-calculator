# 不鎖真實 TA，產品與行銷只服務課堂 demo

評估過幾群券商 app 解不了的真實使用者（多券商／多市場持有者、只想快速瞄一眼的人、紙上交易學習者、幫家人看盤的人、隱私優先者），其中「多券商持有者」最有機會撐起產品。但這條路要處理跨市場匯率歸因才算真差異化，而且不上架等於零商店流量，所有獲客要自己做。決定不走，真實使用者只有課堂上的同學與老師。

後果是優化目標整個換掉：不做差異化、不做獲客、不做留存。只優化兩件事 —— 三秒內看懂，以及任何人可以當場輸入自己手上的股票、看到真的數字。因為交付物只有 APK（ADR-0003），demo 前要先把 app 裝進示範用的手機，不能指望現場讓人安裝。也因為沒有真實使用者要養，產品可以在課程結束後直接停掉。
