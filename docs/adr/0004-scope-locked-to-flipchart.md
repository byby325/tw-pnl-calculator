# 範圍鎖定在「算出未實現盈虧」，不放 AI

課堂 flipchart 定義的核心問題是「你買的股票賺了還是虧了」，輸入股票代號、買入價、數量，輸出盈虧數字。產品就做到這裡為止，不放 LLM。曾評估過一個很窄的 AI 功能（把盈虧拆成匯率貢獻與大盤對比，由程式算、LLM 只負責轉成人話），確認有價值但明確不做。

這是一份「不做」清單，寫下來是為了在開發中途被誘惑時有東西可以指：不做 TWR/XIRR 等績效指標、不做交易對帳單匯入、不做籌碼與市場情緒、不做價格告警與推播、不做新聞、不做 LLM。

技術上這個決定容易回頭（報價 proxy 後端本來就必須存在，見 ADR-0005，加 LLM 只是多一個 endpoint）。記在這裡是因為對一個 BeyondAI 課程專案來說「沒有 AI」本身會讓後來的讀者困惑，需要留下理由。
