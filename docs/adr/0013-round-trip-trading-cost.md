# 交易成本採來回計算，不是只扣買進手續費

計算盈虧時把交易成本定義為「現在全部賣掉要付的總成本」：買進時已經付掉的券商手續費，加上假設此刻賣出要付的券商手續費與證券交易稅。另一個選項是只扣買進手續費，但那會讓數字看起來比實際好 —— 使用者問的是「我現在賣掉到底賺多少」，而賣出的成本是確定會發生的。

費率：券商手續費 0.1425%，買賣各收一次，可套用券商折扣並受單筆最低手續費保護；證交稅只在賣出時課，一般股票 0.3%、ETF 0.1%，以代號 00 開頭判斷是否為 ETF。手續費取整到元並無條件捨去（券商實務），證交稅四捨五入到元，這樣畫面上的分項加起來會剛好等於總計，不會出現差一元的狀況。

預設值是電子下單六折、最低 20 元，這是台股最常見的條件，使用者可以自己改並存在裝置上。預設值錯了算出來就錯，所以折扣與最低手續費直接顯示在摺疊列的標題上，不藏進設定頁。

因此「盈虧」是扣掉交易成本後的淨額，未扣成本的那個數字另外叫「帳面價差」，兩個同時顯示。報酬率的分母是買進成本加買進手續費，也就是實際投入的金額。
