# 只做台股，不支援美股，沒有幣別概念

評估過同時支援台股與美股（美股單檔報價走 Finnhub `/quote`，成本其實很低），好處是 demo 時任何人輸入自己手上的股票都查得到。但一旦有第二種幣別，「總共賺多少」就必須回答用哪天的匯率、匯率波動算不算進盈虧，而那是 lifelio 用整個 `fxAttribution.ts` 在處理的問題。決定只做台股。

因此盈虧一律以新台幣計算，CONTEXT.md 的「盈虧 =（報價 − 買入價）× 數量」不需要幣別欄位，介面上也只會有一個總計數字，與課堂 flipchart 的「輸出：盈虧數字」一致。行情來源收斂到台灣證交所與櫃買中心，不需要 Finnhub API key，也不需要匯率來源。
