# 結果改為按下按鈕才計算，不再隨輸入即時變動

原本每打一個字就重算一次總盈虧。改成輸入與結果分離：填完之後按「計算組合總盈虧」，才把當下的輸入連同當下的報價算成一份結果。這對應課堂 flipchart 的「輸入 → 輸出」框架，也讓 demo 有一個明確的時刻。

按鈕做的不只是顯示已經算好的數字 —— 它會**重新抓一次報價再計算**。原本報價只在加入或移除標的時查一次，使用者開著 app 看再久數字都不會動，而畫面上也沒有任何東西說明這個價是幾點的。現在結果旁邊會標出報價時間，按下按鈕拿到的一定是當下的價。

結果算出來之後若又改了輸入，舊結果會淡化並顯示「輸入已變更，請重新計算」，但**數字維持原樣不會偷偷跟著變**。悄悄把舊結果換成新數字，等於讓使用者以為自己看到的是按過計算的結果，那比顯示過期更糟。每檔卡片上的盈虧也一起淡化，避免一邊是新的股數、一邊是舊的盈虧。

不需要報價就算得出來的部分（總股數、平均成本）仍然即時更新，因為那是使用者正在輸入的東西的直接回饋，壓著不給沒有道理。加入標的時也仍會抓一次報價顯示在卡片上，讓使用者確認自己選對了股票；那只是價格，不是盈虧。
