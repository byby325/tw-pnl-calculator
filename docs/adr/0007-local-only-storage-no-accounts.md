# 持股資料只存在使用者裝置上，沒有帳號系統

既然只服務課堂 demo（ADR-0006），「別人也可以用」的意思是任何人打開就能用，不是任何人都能註冊。持股存在裝置本機，不做註冊、登入、密碼或任何伺服器端的使用者資料。

這同時消掉三件事：帳號系統的開發成本、demo 時的 onboarding 摩擦（開啟 app 直接進畫面，不必先註冊）、以及持有部位這種敏感資料的保管責任 —— 資料不離開手機，就沒有外洩的可能。搭配 ADR-0011 的零後端，整個專案沒有任何伺服器端狀態。

代價：換手機或重裝 app 資料就沒了，而且沒有任何使用行為數據可看。對 demo 用途可接受。
