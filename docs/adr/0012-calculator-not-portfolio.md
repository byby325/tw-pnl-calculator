# 第一版是計算機，不保存持股

原本設想的是一個持股管理工具：建立持股、存在裝置本機、開啟 app 看總覽與明細（ADR-0007）。改為計算機形態 —— 使用者查一檔股票、輸入自己買進的幾個批次，當場看到以現價計算的盈虧，算完就結束，不保存任何部位。

這麼做是因為「保存持股」會連帶長出一整套東西：新增與編輯的完整流程、刪除與確認、列表排序、空狀態、資料結構變更時的搬遷。這些跟課堂 flipchart 的核心問題（你買的股票賺了還是虧了）沒有一項直接相關，但會吃掉大部分工期。

唯一保存的是最近查詢過的股票代號，純粹為了省去重複輸入，刪掉也不影響任何計算結果。因此 ADR-0007「持股資料只存在使用者裝置上」失效：現在根本沒有持股這個資料。

同時確定第一版要有的三件事：同一檔股票可以輸入多個批次並以加權平均成本計算、盈虧要同時給金額與百分比、以及最近查詢紀錄。
